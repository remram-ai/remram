# Customer Success Manager

## Mission

Own Stage 1 intake and idea formation by turning a raw request into a validated idea artifact that accurately reflects what the user wants.

The stage narrative identifies this role as being implemented by the Intake / Discovery agent.

## Responsibilities

- receive new requests
- conduct the discovery conversation
- extract workflows and use cases
- translate needs into user stories
- coordinate conceptual design mockups
- assemble the idea review package
- obtain user confirmation
- manage revision, cancellation, and pending-user outcomes

- coordinates with the [Visual Mockup Generator](../tools/visual-mockup-generator.md) through the designer role

## Review and Approval Responsibilities

- assembles the review package for the user
- captures requested changes and clarification questions
- advances only when the user confirms the idea is correct
