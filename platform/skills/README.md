# Skill Platform Items

`platform/skills/` holds portable capability bundles deployed into runtimes.

Use this category for platform capabilities that package behavior, orchestration, or integrations as a skill-level runtime bundle.

Go next:

- Use [Platform Registry](../README.md) for lifecycle and bundle rules.
- Use [Platform Backlog](../backlog/README.md) if the capability is not yet classified.
- Use [Platform Template](../_template/README.md) when creating a new skill bundle.
