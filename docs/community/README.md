# Community Documentation

This folder contains the contributor-facing documentation for the repository.

Contributions are welcome here. The goal of this folder is to make it easy to understand where to start, how to participate, and how to avoid pushing architecture or documentation changes into the wrong place.

Documents in this folder:

- [Getting Started](getting-started.md) for initial orientation
- [Contribute](contribute.md) for contribution boundaries and expectations
- [Development Workflow](development-workflow.md) for the normal documentation and architecture workflow
- [Repo Setup](repo-setup.md) for local repository setup and adjacent-repo orientation

Use this folder when you need to understand how to work with the repository and the broader RemRam ecosystem as a contributor.
