# Contribute

The easiest way to contribute well is to start in the right repository.

## Contribute Here If You Want To Help With

- project framing
- community-facing docs
- conceptual architecture
- ecosystem positioning
- onboarding material
- idea and product backlog documents

## Contribute Elsewhere If You Want To Help With

- runtime code
- deployment
- memory-system implementation
- APIs
- apps
- reusable agent modules

Those changes belong in the corresponding domain repository.

## Backlog Pipeline

This repository preserves an explicit idea pipeline:

- `backlog/ideas/`
- `backlog/products/`

Use ideas for early concepts.

Use products for more shaped proposals that describe a user-facing or system-facing capability clearly enough to guide later implementation work.

## Good Contribution Pattern

1. Clarify the concept here.
2. Identify the correct ecosystem repository.
3. Move implementation detail into that repository.
4. Keep this repository aligned with the bigger picture.
