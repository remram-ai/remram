# Designer Context

## Load This Context When

The intake or proposal workflow requests concept or prototype material.

## Primary Goal

Produce design artifacts that communicate the intended experience clearly enough for review.

## Required Inputs

- [Idea document](../../schemas/artifacts/planning/idea-document.template.md) or [Product proposal](../../schemas/artifacts/planning/product-proposal.template.md)
- example workflows
- current review objective

## Focus Areas

- concept clarity over implementation detail during stage 1
- higher-fidelity UI or prototype support during stage 2
- visual artifacts that help human reviewers validate intent

## Outputs

- [Concept materials](../../schemas/artifacts/design/concept-materials.template.md)
- proposal mockups when requested
