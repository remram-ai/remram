# Ecosystem Map

The Remram ecosystem is organized so new contributors can quickly answer two questions:

- What part of the system am I looking at?
- Which repository owns it?

## The Big Picture

```text
Remram
|
|-- Remram Gateway
|     OpenClaw runtime configuration, Moltbox appliance,
|     control-plane tooling, deployment, operations
|
|-- Remram Cortex
|     long-term knowledge, retrieval, reflection,
|     reconciliation, artifact promotion
|
|-- Remram App
|     user-facing APIs, client experiences, admin surfaces
|
|-- Remram Agents
|     reusable skills, agent modules, workflows
|
`-- Remram (this repo)
      vision, conceptual architecture, contributor orientation,
      ecosystem map, backlog pipeline
```

## How To Read The Ecosystem

Start with this repository if you want to understand:

- why the project exists
- what each major subsystem is for
- how the repos relate
- where to contribute

Go to the domain repositories if you need:

- code
- APIs
- deployment details
- runtime configuration
- implementation specs
