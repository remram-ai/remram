# Intake and Discovery

Source note: this role document captures the responsibilities assigned to the workbook's "Intake / Discovery Agent."

## Mission

Transform an incoming feature request into an approved idea artifact with enough clarified user intent and concept material to enter the product evaluation backlog.

## Responsibilities

- classify incoming requests
- run discovery interviews
- extract use cases and workflows
- generate feature stories
- synthesize the idea document
- request concept mock generation from the designer role
- assemble and present the user review package
- manage feedback, cancellation, and idle paths until checkpoint 1 resolves

- works with the [Visual Mockup Generator](../tools/visual-mockup-generator.md) through the designer role

## Review and Approval Responsibilities

- sends the review package to the user
- captures user feedback and loops the stage when needed
- advances only when the user confirms accuracy
