# Features

`roadmap/features/` holds initiative-level planning documents.

Features are the second stage in the planning lifecycle:

```text
Idea -> Feature -> Platform Backlog -> Platform Item
```

- Ideas are exploratory concepts.
- Features are initiative-level capabilities that produce or shape one or more platform deliverables.
- Platform items live under [platform/](../../platform/README.md) once they become defined capabilities.

Use the feature template when creating or promoting an initiative:

- [Feature Template](./_template.md)

Go next:

- Read [Ideas](../ideas/README.md) when work is still exploratory.
- Use [Platform Backlog](../../platform/backlog/README.md) when a feature produces a candidate platform deliverable.
- Use [Platform Registry](../../platform/README.md) when a capability becomes an active platform item.
