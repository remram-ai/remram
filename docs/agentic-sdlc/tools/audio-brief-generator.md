# Audio Brief Generator

## Purpose

Convert summaries, proposals, or reports into audio briefings such as podcast-style or narration outputs.

## Typical Usage

- idea review audio
- proposal brief
- architecture brief
- status updates

## Inputs

- document
- optional script

## Outputs

- audio file, for example `mp3`

## Artifact Example

- `/product/ideas/<feature>/brief.mp3`
- `/product/proposals/<feature>/brief.mp3`
