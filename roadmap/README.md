# Roadmap

`roadmap/` holds active planning artifacts for RemRam.

The planning flow is:

```text
idea -> epic -> platform/backlog/<candidate> -> platform/<type>/<name>
```

- `ideas/` captures focused opportunities, experiments, and design hypotheses.
- `epics/` captures larger initiatives that group multiple capabilities or workstreams.

Archived planning history remains in `archive/` and should not be edited in place.
