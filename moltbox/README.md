# Moltbox

Moltbox is the physical appliance side of Remram.

This section is about the thing on the desk: the hardware box, the build styles people can assemble, and the real machines the community runs at home.

It is intentionally different from the conceptual Moltbox document in [docs/overview/moltbox.md](../docs/overview/moltbox.md) and the implementation details in `remram-gateway`.

## What Lives Here

- build archetypes and sizing guidance
- creator and community reference builds
- photos, notes, and rationale behind real Moltboxes
- a place for people to share what they built

## A Moltbox Can Take Different Shapes

- **Edge Moltbox**: light appliance, little or no local model, strong cloud assist
- **Solo Moltbox**: a practical single-user build with a real local routing tier
- **Family Moltbox**: more RAM, more storage, more concurrency, and stronger local capability
- **Sovereign Moltbox**: heavy local AI, bigger GPUs, more independence from cloud reasoning

The point is not one perfect box. The point is a recognizable class of local-first AI appliance that people can actually own, understand, and improve.
