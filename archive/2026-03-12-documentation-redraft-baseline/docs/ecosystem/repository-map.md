# Repository Map

Use this page when you know what kind of change you want to make but are not sure which repository should receive it.

## Work In This Repository If You Are Changing

- README and public-facing project framing
- conceptual architecture
- ecosystem explanation
- onboarding and contributor orientation
- backlog ideas and product proposals

## Work In Remram Gateway If You Are Changing

- runtime behavior
- gateway configuration
- Moltbox deployment
- operator tooling
- implementation docs for the runtime and appliance

## Work In Remram Cortex If You Are Changing

- memory internals
- retrieval behavior
- long-term knowledge services
- reflection and reconciliation implementation

## Work In Remram App If You Are Changing

- user-facing APIs
- apps and client experiences
- admin and operator product surfaces

## Work In Remram Agents If You Are Changing

- reusable skills
- agent modules
- shared workflow logic for agents
