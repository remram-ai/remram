# Use-case Extraction

## Purpose

Convert the interview conversation into structured workflows.

## Inputs

- discovery interview conversation

## Outputs

- structured example workflows

## Steps

1. Review the interview conversation.
2. Extract distinct use cases.
3. Convert those use cases into structured workflows.
4. Produce example workflow outputs.

## Artifacts Created

- example workflow content used in the idea document and review package

## Tools Used

- may use the [Diagram Generator](../tools/diagram-generator.md) when workflows are visualized
