# Product Proposal Generation

## Purpose

Create the complete product proposal document.

## Inputs

- triage findings
- component map
- capability review findings
- implementation approach
- risk and cost assessment
- architectural feedback

## Outputs

- [Product proposal](../../schemas/artifacts/product-proposal.md)

## Steps

1. Create the proposal document at `/roadmap/proposals/<proposal>.md`.
2. Write the executive summary.
3. Write the full proposal body.
4. Include feature overview.
5. Include proposed architecture.
6. Include implementation components.
7. Include risks.
8. Include cost considerations.
9. Include assumptions.
10. Include open questions.

## Artifacts Created

- `/roadmap/proposals/<proposal>.md`

- may use the [Diagram Generator](../tools/diagram-generator.md)
