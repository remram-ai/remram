# Architect

## Mission

Provide a lightweight architectural sanity check before a proposal is finalized for leadership review.

## Responsibilities

- validate proposed system components
- flag architectural risks
- identify major integration concerns
- suggest simpler implementation patterns

## Stages Involved

- [Stage 2 - Product Evaluation and Proposal](../lifecycle/stage-02-product-evaluation-and-proposal.md)

## Task Templates Executed

- [Architecture sanity check](../tasks/architecture-sanity-check.md)

## Tools Used

- may use the [Diagram Generator](../tools/diagram-generator.md) when diagrams help explain architecture concerns

## Review and Approval Responsibilities

- performs a single-pass architectural review before proposal finalization
- does not replace the later full architecture phase
