# Feature Story Generation

## Purpose

Convert workflows into structured user stories that keep the problem framed in user-value terms.

## Inputs

- extracted workflows

## Outputs

- user stories in the format "As a <user> I want <capability> So that <outcome>"

## Steps

1. Review the extracted workflows.
2. Convert each workflow into one or more structured user stories.
3. Format the stories consistently.

## Artifacts Created

- user stories included in the idea document

- not specified in the workbook
