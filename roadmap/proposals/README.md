# Proposals

`roadmap/proposals/` holds proposal-level planning documents.

Proposals are the second stage in the planning lifecycle:

```text
Idea -> Proposal -> Feature
```

- Ideas are exploratory concepts.
- Proposals are decision-ready artifacts awaiting leadership approval.
- Approved features move into [features/](../../features/README.md).

Use the proposal template when creating or promoting a proposal:

- [Proposal Template](./_template.md)

Go next:

- Read [Ideas](../ideas/README.md) when work is still exploratory.
- Use [Features](../../features/README.md) once leadership approval creates an approved feature.
- Use [Platform Registry](../../platform/README.md) when approved feature work produces a defined platform deliverable.
