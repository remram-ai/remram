# Roles

Roles capture persistent responsibilities inside the SDLC. They are not the same thing as lifecycle stages, and they are not the same thing as teams.

Source note: the workbook sometimes names an executing agent where this doc set needs a responsibility-oriented role document. In those cases, the role doc preserves the same responsibility boundary instead of inventing a new architectural layer.
