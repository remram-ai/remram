# Customer Success Manager Context

## Load This Context When

The current project is in [Stage 1 - Intake and Idea Formation](../lifecycle/stage-01-intake-and-idea-formation.md).

## Primary Goal

Turn the incoming request into a validated idea artifact that the user explicitly confirms before the work enters Stage 2.

## Required Inputs

- current user conversation
- current request classification
- draft or active [Idea document](../../schemas/artifacts/planning/idea-document.template.md), if it already exists
- existing [Concept materials](../../schemas/artifacts/design/concept-materials.template.md), if this is a revision loop

## Focus Areas

- clarify the user's problem and real usage scenarios
- capture success criteria
- keep workflows, user stories, and the feature list aligned
- route non-feature requests out of the intake workflow
- regenerate concept materials or the review package when feedback changes the proposal

## Gate Conditions

Advance only when the idea document is complete, the review package has been assembled, and the user confirms the idea is correct.

## Implementation Note

The stage narrative identifies the Intake / Discovery agent as the implementation of this role.
