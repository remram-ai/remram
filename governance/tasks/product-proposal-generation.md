# Product Proposal Generation

## Purpose

Create the complete product proposal document.

## Inputs

- triage findings
- component map
- capability review findings
- implementation approach
- risk and cost assessment
- architectural feedback

## Outputs

- [Product proposal](../../schemas/artifacts/planning/product-proposal.template.md)

## Steps

1. Create the proposal document at `/roadmap/proposals/<proposal>/proposal.md`.
2. Write the executive summary.
3. Write the problem definition.
4. Capture user workflows.
5. Capture capability decomposition.
6. Describe the proposed implementation.
7. List the platform surfaces affected.
8. Record risk assessment.
9. Record cost considerations.
10. Record assumptions.
11. Record open questions.

## Artifacts Created

- `/roadmap/proposals/<proposal>/proposal.md`
