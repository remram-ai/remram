# Reporting Templates

`schemas/artifacts/reporting/` holds templates used to summarize, review, or report on work.

Convention:

- human-authored templates use `.template.md`

Current templates:

- [Product Artifacts](product-artifacts.template.md)
- [Test Plan](test-plan.template.md)

Use the test-plan template for both:

- feature-level master acceptance plans under `features/<feature>/test-plan.md`
- component-level validation plans such as `platform/<type>/<name>/test-plan.md`
