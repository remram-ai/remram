# Idea Review Package Assembly

## Purpose

Assemble the user-facing review package for stage 1 validation.

## Inputs

- idea summary
- workflows
- feature list
- concept visuals
- optional audio briefing

## Outputs

- stage 1 review package sent to the user
- [Audio brief](../../schemas/artifacts/audio-brief.md), when generated

## Steps

1. Assemble the idea summary.
2. Include workflows.
3. Include the feature list.
4. Attach concept visuals.
5. Optionally generate an audio briefing with the [Audio Brief Generator](../tools/audio-brief-generator.md).
6. Send the review message asking the user to confirm the concept.

## Artifacts Created

- review package content for user approval
- [Audio brief](../../schemas/artifacts/audio-brief.md), when generated

## Tools Used

- may use the [Audio Brief Generator](../tools/audio-brief-generator.md)
