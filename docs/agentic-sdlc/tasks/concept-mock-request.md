# Concept Mock Request

## Purpose

Call the designer recipe that generates conceptual mock materials for user validation.

## Inputs

- [Idea document](../artifacts/idea-document.md)
- example workflows

## Outputs

- [Concept materials](../artifacts/concept-materials.md)

## Steps

1. Invoke the designer recipe `conceptual-mock`.
2. Pass the idea document and example workflows as inputs.
3. Generate concept materials that communicate the intended experience.

## Artifacts Created

- conceptual wireframe images
- interaction storyboard
- workflow diagram

## Tools Used

- [Visual Mockup Generator](../tools/visual-mockup-generator.md)
- may use the [Diagram Generator](../tools/diagram-generator.md) for workflow diagrams
