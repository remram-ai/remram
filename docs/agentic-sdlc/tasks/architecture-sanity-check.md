# Architecture Sanity Check

## Purpose

Provide a lightweight architectural review before the proposal is finalized.

## Inputs

- draft implementation approach
- draft proposal content

## Outputs

- architectural feedback
- flagged risks and major integration concerns

## Steps

1. Validate proposed system components.
2. Flag architectural risks.
3. Identify major integration concerns.
4. Suggest simpler implementation patterns where appropriate.

## Artifacts Created

- architecture commentary fed back into the proposal package

- may use the [Diagram Generator](../tools/diagram-generator.md)
