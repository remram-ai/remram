# Architect Context

## Load This Context When

Stage 2 needs the lightweight architectural sanity check before proposal finalization.

## Primary Goal

Catch obvious architectural issues without turning stage 2 into the full architecture phase.

## Required Inputs

- draft proposal
- component map
- implementation approach

## Focus Areas

- validate proposed components
- flag major integration concerns
- identify architectural risks
- suggest simpler patterns where appropriate

## Output

- concise architecture feedback for the proposal package
