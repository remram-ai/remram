# Projects

This page describes the major repositories in the Remram ecosystem.

## Remram

This repository is the public front door.

It owns the project vision, conceptual architecture, ecosystem map, onboarding docs, and backlog pipeline.

## Remram Gateway

This repository owns runtime and appliance implementation work.

It is the home for:

- OpenClaw runtime configuration
- Moltbox deployment and operations
- gateway-side infrastructure
- implementation-facing runtime documentation

## Remram Cortex

This repository owns the long-term knowledge system.

It is the natural home for:

- memory services
- retrieval implementation
- reflection and reconciliation implementation
- durable knowledge internals

## Remram App

This repository owns the user-facing and API-facing application surfaces.

It is where people should expect product and interface implementation to live.

## Remram Agents

This repository owns reusable skills, agent modules, and agent-side building blocks that can be shared across the ecosystem.
