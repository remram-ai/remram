# Idea Document Synthesis

## Purpose

Create the canonical idea artifact.

## Inputs

- feature summary material
- example workflows
- user stories
- initial feature list
- open questions

## Outputs

- [Idea document](../artifacts/idea-document.md)

## Steps

1. Create the canonical idea document at `/backlog/ideas/<feature-name>.md`.
2. Populate the document with the feature summary.
3. Add example workflows.
4. Add user stories.
5. Add the initial feature list.
6. Add open questions.

## Artifacts Created

- `/backlog/ideas/<feature-name>.md`
