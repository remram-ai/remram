# Run Remram

This repository is not the place to start if your goal is to run the full system.

It is the place to understand what the system is.

## If You Want To Explore The Vision First

Start here:

- [What Is Remram?](../overview/what-is-remram.md)
- [System Architecture](../overview/system-architecture.md)
- [Projects](../ecosystem/projects.md)

## If You Want To Run Real Infrastructure

Start with `remram-gateway`.

That repository is the implementation home for the runtime host, Moltbox appliance work, and gateway operations.

## If You Want To Explore Long-Term Memory Internals

Look for `remram-cortex`.

That repository is the right long-term home for detailed memory-system implementation.

## If You Want The User-Facing Experience

Look for `remram-app`.

## If You Want Reusable Skills And Agent Modules

Look for `remram-agents`.
