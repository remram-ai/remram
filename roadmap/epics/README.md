# Epics

`roadmap/epics/` holds initiative-level planning documents.

Epics are the second stage in the planning lifecycle:

```text
Idea -> Epic -> Platform Backlog -> Platform Item
```

- Ideas are exploratory concepts.
- Epics are initiatives that produce or shape one or more platform features.
- Platform items live under [platform/](../../platform/README.md) once they become defined capabilities.

Use the epic template when creating or promoting an initiative:

- [Epic Template](./_template.md)

Go next:

- Read [Ideas](../ideas/README.md) when work is still exploratory.
- Use [Platform Backlog](../../platform/backlog/README.md) when an epic produces a candidate platform feature.
- Use [Platform Registry](../../platform/README.md) when a capability becomes an active platform item.
