# Proposals

`roadmap/proposals/` holds proposal-level planning documents.

This directory is the repository home for Stage 2 proposal outputs.

Proposals are the second stage in the planning lifecycle:

```text
Idea -> Proposal -> Feature
```

- Ideas are exploratory concepts captured in `roadmap/ideas/`.
- Proposals are the decision-ready artifacts created during [Stage 2 - Product Evaluation and Proposal](../../governance/lifecycle/stage-02-product-evaluation-and-proposal.md).
- The canonical Stage 2 artifact is the [Product Proposal](../../schemas/artifacts/product-proposal.md), stored at `/roadmap/proposals/<proposal>.md`.
- Approved proposals become active features in [features/](../../features/README.md).

Use the proposal template when creating or promoting a proposal:

- [Proposal Template](./_template.md)

Go next:

- Read [Ideas](../ideas/README.md) when work is still exploratory.
- Read [Stage 2 - Product Evaluation and Proposal](../../governance/lifecycle/stage-02-product-evaluation-and-proposal.md) for the evaluation loop that produces these documents.
- Use [Features](../../features/README.md) once leadership approval creates an approved feature.
- Read [Stage 3 - Project Formation](../../governance/lifecycle/stage-03-project-formation.md) for the next lifecycle handoff after proposal approval.
- Use [Platform Registry](../../platform/README.md) when approved feature work produces a defined platform deliverable.
