# OpenClaw SME Context

## Load This Context When

Stage 2 needs current OpenClaw ecosystem knowledge before committing to new implementation work.

## Primary Goal

Identify whether the proposal should reuse, extend, or avoid existing OpenClaw capability surfaces.

## Required Inputs

- preliminary component map
- current proposal direction
- available knowledge of OpenClaw core, community extensions, and internal plugins
- `/reference/openclaw/` when relevant reference material exists

## Focus Areas

- current ecosystem awareness
- correct extension-point selection
- avoiding unnecessary reinvention

## Output

- capability review guidance for the product manager
