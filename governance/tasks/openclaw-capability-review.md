# OpenClaw Capability Review

## Purpose

Consult existing capabilities before proposing new development.

## Inputs

- preliminary component map
- current OpenClaw ecosystem knowledge

## Outputs

- identified extension points
- assessment of whether the idea can reuse existing capabilities
- notes on community plugins, internal modules, or OpenClaw core features that affect the proposal

## Steps

1. Review the OpenClaw core platform.
2. Review OpenClaw community extensions.
3. Review existing internal plugins.
4. Review `/reference/openclaw/` when relevant reference material exists.
5. Identify whether the idea should reuse or extend existing capability surfaces.

## Artifacts Created

- capability review findings incorporated into the proposal
