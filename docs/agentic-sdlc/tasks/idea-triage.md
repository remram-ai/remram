# Idea Triage

## Purpose

Evaluate an approved idea and determine whether it should move forward into design exploration.

## Inputs

- approved [Idea document](../artifacts/idea-document.md)

## Outputs

- triage conclusion on whether the idea proceeds
- refined understanding of problem statement and scope

## Steps

1. Validate the problem statement.
2. Review workflows and user stories.
3. Confirm idea uniqueness.
4. Determine overall scope.
