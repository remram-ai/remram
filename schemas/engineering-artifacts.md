# Engineering Artifacts

## Purpose

Engineering artifacts define how the system will be implemented.

## Examples from the Workbook

- `/features/<feature-name>/projects/<project-name>/project-plan.md`
- `/features/<feature-name>/projects/<project-name>/implementation-plan.md`
- `/features/<feature-name>/projects/<project-name>/migration-plan.md`
- `/features/<feature-name>/projects/<project-name>/deployment-plan.md`

## Notes

The workbook says these documents guide implementation agents and engineering teams, but it does not define their schemas in detail.
