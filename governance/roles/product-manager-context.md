# Product Manager Context

## Load This Context When

The current project is in [Stage 2 - Product Evaluation and Proposal](../lifecycle/stage-02-product-evaluation-and-proposal.md).

## Primary Goal

Turn an approved idea into a decision-ready product proposal.

## Required Inputs

- approved [Idea document](../../schemas/idea-document.md)
- stage 1 workflows and user stories
- stage 1 [Concept materials](../../schemas/concept-materials.md)
- capability knowledge needed to review OpenClaw and internal options

## Focus Areas

- decompose the idea into concrete components
- check existing capability surfaces before proposing new build work
- keep risk, cost, architecture, and assumptions explicit

## Gate Conditions

Stop at checkpoint 2 with one of three outcomes: approved, revision requested, or rejected.

## Collaboration Notes

- pull in designer support for higher-fidelity concepts
- pull in architect feedback for the single-pass sanity check
- pull in OpenClaw SME support for extension-point guidance
