# Knowledge vs Memory

One of the most important ideas in Remram is that memory and knowledge are not the same thing.

## Memory

Memory is broad and messy.

It can include:

- transcript history
- temporary context
- retrieved evidence
- partially trusted facts
- work-in-progress updates

Memory is useful, but it is not automatically durable or correct.

## Knowledge

Knowledge is what the system chooses to treat as enduring.

It should be:

- structured
- scoped
- reviewable
- bounded
- connected to provenance

Knowledge is not just "more stored text." It is curated continuity.

## Why The Distinction Matters

If a system treats all memory as truth, it drifts.

If it treats all transcript as durable, it bloats.

If it never promotes stable knowledge beyond the live run, it never compounds.

Remram exists to separate these layers so the system can stay useful over time.
