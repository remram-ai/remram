# Documentation

Repository documentation is organized under `docs/`.

Primary sections:

- `overview/` for project framing and architectural orientation
- `concepts/` for core system concepts and governance models
- `system/` for system behavior and flow documents
- `ecosystem/` for repository and project maps
- `getting-started/` for onboarding and contribution guidance

## Platform Standards

Platform standards define cross-repository contracts that subsystem repositories must implement.

- `standards/capability-integration.md` for the platform-wide capability integration contract
