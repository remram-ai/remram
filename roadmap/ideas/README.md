# Ideas

`roadmap/ideas/` holds exploratory concepts that have not yet been shaped into proposals.

This directory is the repository home for Stage 1 intake outputs.

Ideas are the first stage in the planning lifecycle:

```text
Idea -> Proposal -> Feature
```

- Ideas are exploratory concepts captured during [Stage 1 - Intake and Idea Formation](https://github.com/remram-ai/remram-forge/blob/main/governance/lifecycle/stage-01-intake-and-idea-formation.md).
- The canonical Stage 1 artifact is the [Idea Document](https://github.com/remram-ai/remram-forge/blob/main/schemas/artifacts/planning/idea-document.template.md), stored at `/roadmap/ideas/<idea>.md`.
- Proposals are the Stage 2 planning artifacts waiting for leadership approval.
- Approved features continue implementation under [features/](../../features/README.md) and may later produce platform items in the living [platform registry](../../platform/README.md).

Use the idea template when creating a new idea:

- [Idea Template](./_template.md)

Go next:

- Read [Roadmap](../README.md) for the full planning lifecycle.
- Move to [Proposals](../proposals/README.md) when an idea becomes decision-ready.
- Read [Stage 1 - Intake and Idea Formation](https://github.com/remram-ai/remram-forge/blob/main/governance/lifecycle/stage-01-intake-and-idea-formation.md) for the intake workflow that produces these artifacts.
- Read [Stage 2 - Product Evaluation and Proposal](https://github.com/remram-ai/remram-forge/blob/main/governance/lifecycle/stage-02-product-evaluation-and-proposal.md) for the next lifecycle step after an idea is approved.
- Use [Features](../../features/README.md) once the idea has been approved into active implementation work.
