# Plugin Platform Items

`platform/plugins/` holds active runtime extensions that belong to the native plugin lifecycle.

Use this category for capabilities that extend an existing runtime through the plugin mechanism rather than operating as a service or skill bundle.

Go next:

- Use [Platform Registry](../README.md) for lifecycle and bundle rules.
- Use [Platform Backlog](../backlog/README.md) if the capability is not yet classified.
- Use [Platform Template](../_template/README.md) when creating a new plugin bundle.
