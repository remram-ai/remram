# Implementation Exploration

## Purpose

Define one or more conceptual ways the system could implement the idea.

## Inputs

- triaged idea
- preliminary component map
- capability review findings

## Outputs

- candidate implementation approach

## Steps

1. Identify required plugins.
2. Identify required services.
3. Identify required skills.
4. Identify required configuration changes.
5. Identify integration points.
6. Keep the exploration at conceptual depth rather than full engineering design.

## Artifacts Created

- implementation approach content used in the proposal

## Tools Used

- may use the [Diagram Generator](../tools/diagram-generator.md) for architecture sketches
