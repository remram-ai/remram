# Idea Template

Idea

## Overview

Describe the idea in plain language.
Keep the focus on the opportunity, the intended behavior, and why the concept matters.

## Problem

Describe the friction, gap, or opportunity this idea addresses.
Explain why the current state is insufficient.

## Concept

Explain the core concept at a high level.
Focus on the shape of the idea rather than implementation details.

## Example / Scenario (optional)

Provide a concrete example if it helps clarify the idea.
Show how the idea would behave in practice.

## Potential Value

Describe the user, system, or strategic value if the idea proves worthwhile.

## Open Questions

- What still needs to be clarified?
- What constraints or assumptions need validation?
- What would determine whether this should become a feature?
