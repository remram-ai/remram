# Runtime State Artifacts

## Purpose

Runtime state artifacts store execution state and working memory so agents can resume work, coordinate across roles, and track progress.

## Example Location

- `/features/<feature-name>/projects/<project-name>/_work/`

## Typical Files

- [Project state JSON](project-state-json.md)
- [Agent state JSON](agent-state-json.md)
- [Task state JSON](task-state-json.md)
- [Execution log](execution-log.md)

## Notes

The workbook explicitly ties these artifacts to:

- intermediate notes
- execution progress
- reasoning checkpoints
